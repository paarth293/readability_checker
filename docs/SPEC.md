# Product Specification

## 1.1 Purpose

Help fiction and nonfiction authors quickly understand how readable a chapter is and exactly which sentences cause the most reading friction.

## 1.2 Core User Flow

1. Author opens the page. No sign-up, no friction.
2. Author pastes a chapter into one large input area.
3. Tool analyzes instantly (no button wait for typical sizes).
4. Author sees:
   - A headline readability score with a plain-language interpretation.
   - Supporting metrics (grade level, word count, sentence count, average sentence length, reading time).
   - The full chapter text with the **five hardest sentences highlighted** and ranked 1 to 5.
   - A side list of the five hardest sentences with the reason each is hard.
5. Author can click a ranked sentence to jump to it in the text, edit the text, and re-analyze.

## 1.3 In Scope

- English-language text analysis.
- One headline readability score plus supporting standard formulas.
- Top five hardest sentences, ranked, with reasons.
- Light and dark themes.
- Fully responsive, fully keyboard-accessible, screen-reader friendly.
- Privacy-first: the chapter never leaves the author's browser.
- Copy-friendly results.

## 1.4 Explicit Non-Goals

- User accounts, logins, saved documents, cloud sync.
- Databases or any server-side storage of manuscripts.
- AI rewriting or suggestions generated by language models.
- File uploads (.docx, .pdf), export formats, or integrations.
- Multi-language support.
- Ads, paywalls, tracking of text content.
- Grammar checking or style checking.

## 1.5 Success Criteria

| Area                                                         | Target                                           |
| ------------------------------------------------------------ | ------------------------------------------------ |
| Analysis time, 5,000 words                                   | under 100 ms                                     |
| Analysis time, 50,000 words                                  | under 1,000 ms                                   |
| Main thread blocking during analysis                         | none (analysis runs off the main thread)         |
| Largest Contentful Paint on mid-range mobile                 | under 1.5 s                                      |
| Initial JavaScript, compressed                               | under 100 KB                                     |
| Lighthouse (Performance, Accessibility, Best Practices, SEO) | 95 or higher each                                |
| Accessibility                                                | WCAG 2.2 AA, zero automated violations           |
| Concurrent users sustained                                   | 10,000 or more with no errors and stable latency |
| Manuscript text transmitted to any server                    | zero bytes                                       |
